# Бот для Instagram-канала «Факты и новости»

Один запуск делает один пост:

1. **Сбор материалов.** Свежие новости из RSS (список в `sources.json`) или события «в этот день» из русской Википедии. Типы чередуются: новость, факт, новость…
2. **Текст.** Нейросеть выбирает самый любопытный материал и пишет заголовок, короткий текст для картинки, подпись и хэштеги. Писать он может только по тексту источника, без выдуманных деталей. По умолчанию работает бесплатная модель GitHub Models (`openai/gpt-4.1-mini`), ей не нужен никакой ключ: в GitHub Actions хватает встроенного доступа. Если добавить секрет `ANTHROPIC_API_KEY`, тексты будет писать Claude.
3. **Картинка.** 1080×1350 (4:5), градиент в цвет рубрики, плашка категории, заголовок, текст, ник канала и источник. Примеры: `examples/demo-space.jpg`, `examples/demo-history.jpg`.
4. **Публикация.** Картинка выкладывается по публичной ссылке, затем пост создаётся через Instagram Graph API.
5. **Повторы.** История в `data/history.json`, один материал дважды не публикуется.

Расписание: GitHub Actions, 3 поста в день (09:00, 14:00, 19:00 по Москве), меняется в `.github/workflows/post.yml`.

**По умолчанию бот ничего не публикует.** Пока переменная `PUBLISH` не равна `true`, он только готовит картинку и подпись: их можно скачать во вкладке Actions (артефакт `post`).

## Что нужно от вас

| Что | Где взять |
|---|---|
| Профессиональный аккаунт Instagram (Бизнес или Автор) | Instagram → Настройки → Тип аккаунта и инструменты |
| Страница Facebook, связанная с этим аккаунтом | Instagram → Настройки → Центр аккаунтов, или в настройках страницы Facebook |
| Приложение Meta и токен доступа | developers.facebook.com, шаги ниже |
| Аккаунт GitHub с **публичным** репозиторием | Нужен для расписания и чтобы Instagram мог скачать картинку по ссылке |
| Ключ Claude API (по желанию, но сильно лучше) | console.anthropic.com → API Keys |

### Получение токена Instagram

**Простой способ (вход через Instagram, страница Facebook не обязательна).** В приложении Meta откройте сценарий «Управление сообщениями и контентом в Instagram» → «Персонализируйте» → «Настройка API со входом через Instagram» → «Создайте токены доступа» → «Добавить аккаунт», войдите в аккаунт канала. Рядом с аккаунтом появятся его ID (`IG_USER_ID`, можно не указывать: бот узнает его по токену) и кнопка «Создать токен» (это `IG_ACCESS_TOKEN`, начинается с `IGAA`, живёт 60 дней, продлевается функцией `refresh_instagram_token`). Бот сам поймёт по токену, что нужно ходить на graph.instagram.com.

**Способ через Facebook (если нужен):**

1. developers.facebook.com → **My Apps → Create App**, тип **Business**.
2. В приложении добавьте продукт **Instagram** (вариант «API setup with Facebook login»).
3. Откройте **Graph API Explorer** (Tools → Graph API Explorer), выберите своё приложение и выдайте разрешения:
   `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`, `business_management`.
   Нажмите **Generate Access Token** и войдите.
4. Узнайте ID Instagram-аккаунта: в Explorer выполните
   `me/accounts?fields=name,instagram_business_account`
   Число в `instagram_business_account.id` и есть `IG_USER_ID`.
5. Короткий токен живёт час, сделайте долгий (60 дней): **Access Token Debugger → Extend Access Token**.
   Долгий токен и есть `IG_ACCESS_TOKEN`. Раз в ~50 дней его нужно продлевать тем же способом (или функцией `refresh_long_lived_token` в `bot/instagram.py`).

Пока приложение в режиме разработки, публиковать можно в свой аккаунт, если вы администратор приложения. Проверка приложения (App Review) нужна только если бот будет работать с чужими аккаунтами.

### Настройка GitHub

1. Создайте публичный репозиторий и загрузите в него содержимое этой папки.
2. **Settings → Secrets and variables → Actions**:
   - Secrets: `ANTHROPIC_API_KEY`, `IG_ACCESS_TOKEN` (`IG_USER_ID` по желанию) (и `IMGBB_API_KEY`, если выберете imgbb).
   - Variables: `CHANNEL_HANDLE` (например `@facts_daily`), `PUBLISH` = `false` на время проверки.
3. **Actions → Instagram post → Run workflow**: пробный прогон. Скачайте артефакт `post`, посмотрите картинку и подпись.
4. Когда результат устраивает, поставьте переменную `PUBLISH` = `true`. С этого момента посты уходят по расписанию.

Если репозиторий должен быть приватным, задайте переменную `IMAGE_HOST` = `imgbb` и секрет `IMGBB_API_KEY` (бесплатно на api.imgbb.com): картинки будут храниться там.

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните и выполните: set -a; . ./.env; set +a
python main.py --sample        # офлайн-проверка рендера, без сети
python main.py --kind fact     # подготовить пост с фактом, без публикации
python main.py --publish       # подготовить и опубликовать
```

## Настройка под себя

- **Источники:** `sources.json`, любые RSS-ленты. Сейчас там N+1, Naked Science, Лента.ру, РИА Новости.
- **Тон и темы:** промпт `SYSTEM` в `bot/writer.py` (например, исключить или добавить темы).
- **Дизайн:** цвета рубрик и шрифты в `bot/render.py`. Шрифт Montserrat скачивается в Actions; локально, если его нет в `fonts/`, используется DejaVu.
- **Частота:** строка `cron` в `.github/workflows/post.yml`. Лимит Instagram API: 50 публикаций за сутки.

## Стоимость

GitHub Actions для публичного репозитория бесплатен. Claude: один пост ≈ несколько тысяч токенов, порядка нескольких центов на пост на модели по умолчанию (`claude-opus-5`); дешевле можно, указав переменную `CLAUDE_MODEL` = `claude-sonnet-5` или `claude-haiku-4-5`.

## Про права на контент

Бот пересказывает материал своими словами и указывает источник на картинке и в подписи, ссылки не копирует целиком. Картинки источников не используются, только сгенерированный фон и текст.
